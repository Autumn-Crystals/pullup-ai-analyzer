Dataset Cleaning, Normalization & Stratified Splitting

Validated on 4K/1080p footage with H.264 CRF 23 compression and 70/15/15 dataset splits.

70% Training Split

70 frames / sets allocated for kinematic dead-hang calibration, bounding box anchors, and baseline joint regression parameters.

15% Validation Split

15 frames / sets for hyperparameter tuning, hang-tolerance tuning (±0.06), and ascent/descent velocity threshold selection.

15% Holdout Test Split

15 frames / sets strictly reserved for final SOTA model benchmarking, mAP calculation, and cross-architecture generalization testing.

Deployment Guide: Vercel & Streamlit Cloud

How to run locally, push to GitHub, and deploy across both cloud platforms.

1. Run the Interactive Streamlit App Locally

# Clone repository and enter directory
cd "d:\ML Project"

# Install dependencies
pip install -r requirements.txt

# Launch interactive UI
streamlit run app.py

2. Upload Code to GitHub

# Initialize or set your target GitHub remote
git remote set-url origin https://github.com/Autumn-Crystals/pullup-ai-analyzer.git

# Stage all files
git add .

# Commit with academic project metadata
git commit -m "feat: complete SOTA pull-up kinematics analyzer, multi-model benchmark, and light UI"

# Push to your GitHub repository
git push -u origin main

3. Deploy to Vercel (Web Showcase & Portal)

# Deploy directly with Vercel CLI
npx vercel --prod

4. Deploy to Streamlit Community Cloud (Interactive ML App)

Go to share.streamlit.io → Connect your GitHub account → Select your repository → Set Main file path to app.py → Click Deploy.
